## 技术要点

- 天空为自定义 shader 球，片元内用 `normalize(vWorldPos - cameraPosition)` 求方向（顶点插值在球内会失真）
- 尾焰为自定义软边 shader 锥（沿轴 `pow(1-t,fall)` × 沿周 `uv.x` 轮廓柔化 × 三段颜色：喷口白芯 → 中段饱和橙 → 尾端暗红），
  外/中/芯三层加色叠加，opacity 收敛在 0.15/0.19/0.30——7 个锥相加一旦过 1 就会被 ACES 拉成白柱
- 烟雾为 GPU Points 粒子，单 draw call；密度滑块实时改变发射率。导流槽焰流带方向初速沿 Z 轴槽口外喷
- 昼夜通过 uniform 插值 + 两张 PMREM 环境贴图切换 IBL

### 太空段（飞出地球）

- 地球半径 12000 m，球心 y = -12000；地平线俯角因此落在广角画面下半部，火箭飞出大气后仍能看到弧线
- 大气壳不是"球壳边缘高光"，而是片元内按视线到地心的冲击参数算指数密度：
  `hgt = |oc × rd| - R`，`dens = exp(-hgt/130) × smoothstep(-45, 0, hgt)`。
  负值一侧归零（大气在地球背后，被地球挡住），轮廓处保留 45 km 渐变去填地球 alpha 渐隐露出的背景——否则弧线上会出现一圈黑缝
- 地球轮廓用极窄 alpha 渐隐（`smoothstep(0, 0.014, dot(vd,n))`）；**不要**把轮廓混成亮蓝，那会画出一圈蓝色虚线
- 城市灯光是全片唯一的高频项，地平线处一像素横扫几十公里会逐像素随机点亮成暖白斑点，必须乘 LOD 与掠射系数抑制
- 球体细分 512 × 288：256 段时轮廓每段约 5 px，几何锯齿比任何着色器 AA 都粗
